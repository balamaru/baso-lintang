# Font lokal

Font referensi disimpan lokal agar browser tidak mengakses CDN font.

- Bricolage Grotesque: https://github.com/google/fonts/tree/main/ofl/bricolagegrotesque
- Source Sans 3: https://github.com/google/fonts/tree/main/ofl/sourcesans3

Berkas variable TTF diambil 21 Oktober 2026. Lisensi SIL Open Font License masing-masing
disertakan pada berkas `*-OFL.txt`. Font digunakan sesuai arahan `docs/fe.html`.
